Why Bash?

What bash scripting actually is

A bash script is a text file containing the same commands you type in the terminal — but saved so they run automatically, in sequence, with logic (if/else, loops) and reuse (functions). Your notify.sh, health.sh, backup.sh are bash scripts. Bash is available everywhere on Linux, requires no compilation, and is the glue that holds servers together.

Python is often better for complex programs, but bash is unbeatable for: running commands, manipulating files and text, automating system tasks, writing quick one-off scripts, and chaining tools together. If it would take 5 manual terminal steps, make it a script.

Conditionals

if in bash tests exit codes

Unlike Python/JS where if tests a boolean, bash if tests the exit code of a command. [ ... ] and [[ ... ]] are commands that return exit code 0 (true) or 1 (false). Always use double brackets [[ ]] in bash scripts — they're safer and support more features.

conditionals.sh
# String comparison if [[ "$SERVER" == "dell" ]]; then echo "Dell server" elif [[ "$SERVER" == "lenovo" ]]; then echo "Lenovo" else echo "Unknown" fi
# Number comparison: -eq -ne -lt -le -gt -ge if [[ $DISK_PCT -ge 90 ]]; then echo "CRITICAL disk" fi
# File tests if [[ -f "/etc/ssh/sshd_config" ]]; then # -f file, -d dir, -e exists echo "file exists" fi
# Check if a command is installed if command -v curl &>/dev/null; then echo "curl is available" fi

Error Handling

The safe script header

Always start scripts with set -euo pipefail. Without it, scripts keep running even after errors, leading to partial and broken states that are hard to debug.

error-handling.sh
#!/bin/bash set -euo pipefail # e=exit on error, u=unset var = error, o pipefail
# trap — run this function when script exits (any reason) cleanup() { rm -f /tmp/my.lock; } trap cleanup EXIT
# Custom error handler with line number on_error() { echo "ERROR at line $1" /home/dell/scripts/notify.sh "❌ Script failed at line $1" } trap 'on_error $LINENO' ERR
# Check if a tool exists before using it if ! command -v curl &>/dev/null; then echo "Error: curl not installed" exit 1 fi

Real Scripts

Service Monitor — Check All Services, Alert on Any Down

/home/dell/scripts/service-monitor.sh
#!/bin/bash set -euo pipefail
SERVICES=("ssh" "syncthing@dell" "fail2ban") DOWN=()
for svc in "${SERVICES[@]}"; do if ! systemctl is-active --quiet "$svc"; then DOWN+=("$svc") fi done
if [[ ${#DOWN[@]} -gt 0 ]]; then MSG="⚠️ Services DOWN:\n$(printf '• %s\n' "${DOWN[@]}")" /home/dell/scripts/notify.sh "$MSG" fi

Log Rotate + Archive

/home/dell/scripts/clean-logs.sh
#!/bin/bash set -euo pipefail
LOG_DIR="/var/log" MAX_AGE=30
BEFORE=$(du -sh "$LOG_DIR" | cut -f1) find "$LOG_DIR" -name "*.gz" -mtime +$MAX_AGE -delete AFTER=$(du -sh "$LOG_DIR" | cut -f1) echo "Freed space: $BEFORE → $AFTER"
