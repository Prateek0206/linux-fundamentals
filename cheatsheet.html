Create empty file or update timestamp
mkdir -p dir/sub
Create directory (and parents)

Copy file

mv file.txt newname.txt
Rename file

rm file.txt
Delete a file permanently
rm -rf dir/

less file.txt
Scroll through file (q to quit)
head -20 file.txt
Show first 20 lines
tail -20 file.txt
Show last 20 lines
tail -f file.txt
Follow file in real time (great for logs)
nano file.txt
Edit file (Ctrl+O save, Ctrl+X exit)
find / -name "*.pdf"
Find files by name pattern
find . -mtime -7

find . -size +100M

🔒 Permissions
ls -la
Show permissions for all files
chmod 755 script.sh
rwxr-xr-x (executable script)
chmod 644 file.txt
rw-r--r-- (regular file)
chmod 600 private.key
rw------- (private key / secrets)
chmod +x script.sh
Make file executable
chmod -R 755 dir/
Set permissions recursively
chown user:group file
Change file owner and group
chown -R dell:dell dir/
Change ownership recursively
umask 022
Default permissions mask for new files
getfacl file.txt
Show ACL permissions
📝 Text Processing
grep "pattern" file
Search for pattern in file
grep -r "pattern" .
Recursive search in current dir
grep -i "pattern" file
Case-insensitive search
grep -v "pattern" file
Lines NOT matching pattern
grep -n "pattern" file
Show line numbers in results
sed 's/old/new/g' file
Replace all occurrences of text
sed -i 's/old/new/g' file
Replace in-place (modifies file)
awk '{print $2}' file
Print 2nd column of each line
awk -F: '{print $1}' /etc/passwd
Use : as delimiter, print 1st field
cut -d: -f1 /etc/passwd
Cut field 1 using : delimiter
sort file.txt
Sort lines alphabetically
sort -n -r file.txt
Sort numerically, reversed
sort | uniq -c | sort -rn
Count occurrences, sort by frequency
tr -d '\n' < file
Remove newlines from file
tr 'a-z' 'A-Z' < file
Convert to uppercase
xargs
Build and execute commands from stdin

pkill syncthing

killall syncthing

jobs

renice -n 5 -p 1234
Change priority of running process

alias ll='ls -la'

time command

history | tail -20
